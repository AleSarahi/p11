# Módulo `d1`

Crea una base de datos **Cloudflare D1**.

## Inputs

| Nombre | Descripción | Tipo |
|---|---|---|
| `account_id` | Cloudflare account ID | `string` (sensitive) |
| `database_name` | Nombre de la base de datos | `string` |

## Outputs

| Nombre | Descripción |
|---|---|
| `id` | ID de la base de datos D1 |
